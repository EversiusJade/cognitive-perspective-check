# 对话演示脚本

实际录屏尚未完成。下面是一段约 90 秒的拍摄顺序；对话需要在真实客户端运行，不能把设计中的回答剪成实测结果。

先展示 Release 中的 Skill ZIP。解压后，把整个文件夹放进客户端技能目录。已经安装时只展示位置，不重复复制到另一个扫描目录。

新建聊天并点名调用，输入：“我们想给小店做个 App 提高收入，但还不知道瓶颈。请先帮我理清思路，别问太多。”展示实际补问和回答，突出不同解释怎样改变第一步。

根据实际回答选一个分支，例如验证复购问题。继续展示同一背景下的检查方法、成立条件和待查事实。画面标明哪些是建议或假设，哪些来自真实记录。

最后换新聊天，输入：“使用 cognitive-perspective-check。已经决定降价30%，只写一段100字以内的公告。”展示是否直接交付并停止。额外说明、菜单或重开分析均应如实保留。

录屏注明客户端、模型和版本。它展示一次使用过程，不代表平均效果或成本。发布前由作者确认对话没有敏感信息。
