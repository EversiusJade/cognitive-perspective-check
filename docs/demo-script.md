## 保存与剪辑

1. 保存原始请求、模型答复、版本、时间和可获得的调用记录。只用自身或合成资料；录制前收起无关页面和个人信息。
2. 先保存完整原片，再制作约 90 秒的展示版。允许压缩等待段，字幕标明“等待已加速”或“等待已剪去”。
3. 截取原始回答可注明节选；不改写、拼造 AI 答案，不把作者脚本动画称为真实录屏。
4. 推荐发布 MP4/WebM 及一张静态预览图。需要 README 内联预览时另做较短 GIF，完整视频保留可读文字。
5. README 的视频入口只在文件实际存在并可打开后添加。记录展示失败和重录原因，避免把筛选后的一次成功当作典型效果。

当前工具可以采集 Codex CLI 日志，尚不能直接录制桌面画面。若制作日志回放，应明确标注“CLI 日志回放”，与桌面录屏区分。
