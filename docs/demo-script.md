# 约 90 秒的演示脚本

录屏还没拍。按下面的顺序在真实客户端操作，保留实际回答。

先展示 Release 的 Skill ZIP。解压，把整个文件夹放进技能目录；已经安装的，只展示位置，别再复制到另一个扫描目录。

新建聊天，点名调用，输入：“我们想给小店做个 App 提高收入，但还不知道瓶颈。请先帮我理清思路，别问太多。”展示补问和回答，看看不同解释怎样改变第一步。

按实际回答选一个分支，比如验证复购问题。展示同一背景下的检查方法、成立条件和待查事实，标明哪些是建议或假设，哪些有真实记录。

另开聊天，输入：“使用 cognitive-perspective-check。已经决定降价30%，只写一段100字以内的公告。”观察是否交付后停止。多出的说明、菜单或分析也留在画面里。

注明客户端、模型和版本。发布前由作者确认没有敏感信息。录屏只展示这一次使用，不能代表平均效果或成本，也不能把设计好的回答剪成实测。
