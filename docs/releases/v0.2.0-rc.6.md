# 认知视角检查器 v0.2.0-rc.6

## 改动

- 删除 PowerShell 安装程序、两个 CMD 安装入口和对应安装检查脚本。各系统使用同一份 Skill ZIP，解压后复制整个技能文件夹。
- 针对 Issue #1 明确分支优先级：点名调用不强制展开完整分析。用户已决定并请求固定成果时，交付后停止；原因存疑也不自动重开决策。
- 只在影响成果使用时补充一句提醒，不追加比较、测算、推荐章节或继续菜单。只要正文的请求优先按正文交付。
- 加入降价公告示例及三个回归场景，覆盖已确定任务、只要正文，以及仍在考虑的决策。

## 下载

下载 `cognitive-perspective-check.zip`。目录、更新和卸载见仓库的 `INSTALL.md`，校验值见 `SHA256SUMS.txt`。旧版 Windows 附件属于历史版本。

本次是规则和分发方式修订，没有新增客户端模型实验。Issue #1 的行为问题尚待复测；三个回归场景的状态为 `not_run`。已有 8 次 Codex 采集仍对应 rc.4，不构成 rc.6 的效果或成本证明。
