# 认知视角检查器 v0.2.0-rc.6

## 改了什么

- 删除 PowerShell 安装程序、两个 CMD 安装入口和对应的安装检查脚本。各系统改用同一份 Skill ZIP，解压后复制整个技能文件夹。
- 针对 Issue #1，明确点名调用也不必展开完整分析。用户已决定方向并请求固定成果时，交付后停止；即使原因存疑，也不自动重新讨论决策。
- 只有影响成果使用时，才补充一句提醒；不追加比较、测算、推荐章节或继续菜单。用户只要正文时，优先按要求交付正文。
- 加入降价公告示例和三个回归场景，分别覆盖已确定任务、只要正文和尚在考虑的决策。

## 下载

下载 `cognitive-perspective-check.zip`。目录、更新和卸载见仓库的 `INSTALL.md`，校验值见 `SHA256SUMS.txt`。旧版 Windows 附件属于历史版本。

## 验证状态

这次修改了规则和分发方式，没有新增客户端模型实验。Issue #1 的行为问题尚待复测，三个回归场景的状态为 `not_run`。已有 8 次 Codex 采集仍对应 rc.4，不能证明 rc.6 的效果或成本。
