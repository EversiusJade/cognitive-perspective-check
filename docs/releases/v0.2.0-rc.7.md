# 认知视角检查器 v0.2.0-rc.7

交付前增加一次有限 review，检查最终建议是否仍服务用户的目标，以及分析中的假设有没有在成稿里变成事实。

## 这次改了什么

- 复核目标和约束、视角的实际差异、证据与推演的区分、建议和交付成果。
- 把已有的成果完成检查并入这一次 review，避免重复复核。
- 已确定的任务只检查成果，不重新打开决策；提问和视角限额不变。
- 不因 review 自动搜索、启动其他代理或新增推演。影响选择的修正和缺口需要说明，不默认展示内部检查清单。
- 同步核心规则、深入指导、README、安装说明和设计取舍。

下载 `cognitive-perspective-check.zip`，复制整个技能文件夹即可更新。校验值见 `SHA256SUMS.txt`。
