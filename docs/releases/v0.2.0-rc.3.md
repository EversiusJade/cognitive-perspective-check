# 认知视角检查器 v0.2.0-rc.3

这个候选版继续以减少用户与 AI 过早认知窄化为目标，补充了可用成果、判断依据和目标边界的要求。理解背景之后，还要找出核心问题、比较视角与取舍、解释条件后果、给出建议，并完成用户选定的后续工作。

## 改了什么

- 在同一组明确目标和约束下比较视角。新目标或优先级要标为提议，AI 不能暗中更换成功标准来改方向。
- 没有可靠依据时，不强行排序。说明各条路线的成立条件，给出既能区分路线、又符合用户约束的下一步。
- 影响判断的论据要对应用户观察或可识别来源；没有支持则标为假设。推演结果不作为事实证据。
- 用户已要求方案、文案或文件时，第一轮尽可能给出可用产物。用户选择继续后，完成所选成果；确实需要转交时才给交接摘要。
- 提问限额按所需信息项计数，不能把长问卷算作一问。达到限额不代表背景已完全掌握，结论仍需保留条件。
- 增加完整作者演示：从模糊需求、少量补问和条件方案，走到用户纠正后的具体交付。
- 说明安装包不含维护者测试文件、同版本在不同渠道的文件集差异，以及隐式调用配置与客户端实际发现的区别。安装程序未改。

## 下载与更新

Windows 用户下载 `cognitive-perspective-check-v0.2.0-rc.3-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，选一种位置。手动安装下载 `cognitive-perspective-check.zip`。`SHA256SUMS.txt` 提供两个 ZIP 的校验值。

已有同名内容默认保留。更新请按 `INSTALL.md` 使用显式替换与备份选项，建议沿用原安装渠道。旧版本及附件保留，不覆盖历史发布。

## 证据范围

这次完成了独立静态审查、规则修订和作者演示，没有新增模型行为实验或安装测试。保留的 rc.1 历史记录不能证明 rc.3 的真实用户效果、自然调用、相对竞品增益或 token 节省。项目的区别在于流程组合和明确的成果要求，尚未验证优于竞品。行为限额不能单独控制模型后台推理的硬 token 上限。
