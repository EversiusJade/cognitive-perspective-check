# 认知视角检查器 v0.2.0-rc.3

本候选版保留减少用户与 AI 过早认知窄化的主旨，补齐可用成果、判断依据与目标边界。理解背景是起点，后续仍包括核心问题、视角取舍、条件后果、建议与用户选定的深入。

## 本次修订

- 视角比较基于相同的明确目标和约束。新目标或优先级要标为提议；AI 不能通过更换成功标准暗中改方向。
- 无可靠依据时不强行排序。说明各路径成立条件，给能够区分路线、且符合用户约束的下一步。
- 对左右判断的论据，连接用户观察或可识别来源；没有支持则标为假设。推演结果仍不作为事实证据。
- 当用户已经要求方案、文案或文件，第一轮尽可能直接包含可用产物；选择继续后完成所选成果，确实需要转交时才给交接摘要。
- 限额按所需信息计数，不把长问卷算作一问；达到限额不代表背景已完全掌握，保留条件结论。
- 增加一段从模糊需求、少量补问、条件方案到用户纠正后具体交付的完整作者演示。
- 澄清安装包不含维护者测试文件、同版本跨渠道文件集差异，以及隐式调用配置与客户端实际发现的区别。安装程序保持不变。

## 下载与更新

Windows 用户下载 `cognitive-perspective-check-v0.2.0-rc.3-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，选一种位置。手动安装下载 `cognitive-perspective-check.zip`。`SHA256SUMS.txt` 提供两个 ZIP 的校验值。

已有同名内容默认保留。更新请按 `INSTALL.md` 使用显式替换与备份选项；建议沿用原安装渠道。旧版本及附件保留，不覆盖历史发布。

## 证据范围

本轮为独立静态审查、规则修订与作者演示，未新增模型行为实验或安装测试。rc.1 的历史记录保留，不能用来证明 rc.3 的真实用户效果、自然调用、相对竞品增益或 token 节省。差异化是流程组合与明确的成果要求；尚未验证胜出。行为限额不能独立控制模型后台推理的硬 token 上限。
