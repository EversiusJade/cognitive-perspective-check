# 问题框架校准器 v0.2.0-rc.1

面向模糊、带预设的早期需求：AI 先提炼目标，只补问会改变方向的少数信息，解释不同问题框架如何改变行动与取舍，再由用户选择是否深入。

## 下载与安装

- Windows 用户：下载 `cognitive-perspective-check-v0.2.0-rc.1-windows.zip`，完整解压后双击 `install-copilot.cmd`；Codex 与 Copilot 共用时选 `install-shared.cmd`。两种位置选一种。
- 手动安装：下载 `cognitive-perspective-check.zip`，解压后将整个 `cognitive-perspective-check` 文件夹复制到客户端支持的 `skills` 目录。
- `SHA256SUMS.txt` 提供两个 ZIP 的 SHA-256 校验值。

完整步骤见 [安装说明](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.1/INSTALL.md)。安装不需要管理员权限、Python、Node 或 GitHub 凭证。

## 本版本的范围

- 通常不补问或只问一个关键问题；初始对齐累计最多三个。
- 通常展示两个有实际行动差别的框架，最多三个。
- 同时检查用户预设和 AI 的初步判断，给出有条件的建议。
- 先做一次简短校准，再深入用户选中的验证、比较、推演或执行分支。
- 已明确的事实问题与执行任务直接交付。

首次使用可明确点名：

> 使用 cognitive-perspective-check。我们想给小店做一个 App 提高收入，但还没确定瓶颈。先帮我校准问题，简短一点。

## 验证与反馈

这是 候选版本（pre-release）。安装程序已有 Windows PowerShell 5.1 下的 12 项安装检查记录；仓库包含四组新旧版本回答样例和作者评阅。尚未完成长期真实用户验证、实际客户端自然触发率与真实 token 消耗的测量。skill 中的步骤和长度约束不能独立保证后台 token 上限。

详见 [验证记录](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.1/evals/validation.md)。欢迎通过 [Issues](https://github.com/EversiusJade/cognitive-perspective-check/issues) 报告使用场景、客户端/模型、实际回答和预期改进。
