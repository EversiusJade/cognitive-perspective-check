# 问题框架校准器 v0.2.0-rc.1

早期需求还模糊、方向里带着预设时，AI 先理清目标，只问少数会改变方向的问题，再解释不同问题框架带来的行动与取舍，由用户决定是否深入。

## 下载与安装

- Windows 用户：下载 `cognitive-perspective-check-v0.2.0-rc.1-windows.zip`，完整解压后双击 `install-copilot.cmd`；Codex 与 Copilot 共用时选 `install-shared.cmd`。两种位置选一种。
- 手动安装：下载 `cognitive-perspective-check.zip`，解压后将整个 `cognitive-perspective-check` 文件夹复制到客户端支持的 `skills` 目录。
- `SHA256SUMS.txt` 提供两个 ZIP 的 SHA-256 校验值。

完整步骤见 [安装说明](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.1/INSTALL.md)。安装不需要管理员权限、Python、Node 或 GitHub 凭证。

## 这个版本做什么

- 通常不补问或只问一个关键问题；初步理解背景时，累计最多问三个。
- 通常比较两个能带来实际行动差别的框架，最多三个。
- 检查用户预设和 AI 的初步判断，给出有条件的建议。
- 先简短校准，再深入用户选中的验证、比较、推演或执行分支。
- 事实问题和执行任务已经明确时，直接交付。

首次使用可以点名调用：

> 使用 cognitive-perspective-check。我们想给小店做一个 App 提高收入，但还没确定瓶颈。先帮我校准问题，简短一点。

## 验证与反馈

这是候选版本（pre-release）。安装程序已有 Windows PowerShell 5.1 下的 12 项安装检查记录；仓库收录了四组新旧版本回答样例和作者评阅。长期真实用户验证、实际客户端自然触发率和真实 token 消耗的测量尚未完成。skill 的步骤和长度约束不能单独保证后台 token 上限。

详见 [验证记录](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.1/evals/validation.md)。使用反馈可提交到 [Issues](https://github.com/EversiusJade/cognitive-perspective-check/issues)，请附上场景、客户端/模型、实际回答和预期改进。
