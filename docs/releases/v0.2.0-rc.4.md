# 认知视角检查器 v0.2.0-rc.4

本候选版保留既定范围与目的，精简核心入口，并补齐有限覆盖、用户扩大范围与成果交付的使用边界。

## 调整

- 首轮少量视角是有限比较，不代表穷尽。仅提示可能改变建议的未评估因素；新背景使旧视角失效时替换相关部分。
- 默认少量问题、视角和单个深入分支；用户明确选择更广覆盖时，服从已授权范围和预算。
- 已请求的成果继续直接交付；交付前做一次目标、约束和格式检查，明确计划提议与已完成动作的差别。
- 合并核心入口的重复说明，保留关键约束。可见文字缩短不是后台 token 节省的证明。
- 新增 GitHub 使用反馈模板，帮助报告实际理解、选择与交付的收益或阻碍。
- 更新发布记录，确认 About 简介和八个 Topics 已生效。稳定标识、MIT 与安装程序保持不变。

## 安装与更新

Windows 下载 `cognitive-perspective-check-v0.2.0-rc.4-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，选一种位置。手动安装下载 `cognitive-perspective-check.zip`。两个 ZIP 的校验值见 `SHA256SUMS.txt`。

同名内容不同仍默认保留；按 `INSTALL.md` 显式备份更新。旧版本与附件保留。

## 验证边界

本轮是静态角色走查、内容精简与分发修订，没有新增安装测试或模型行为实验。rc.1 历史记录不证明 rc.4 的效果。用户收益、自然调用、成本节省和竞品增益仍未验证。
