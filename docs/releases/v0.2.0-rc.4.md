# 认知视角检查器 v0.2.0-rc.4

这个候选版沿用既定范围与目的，缩短核心入口，并说明少量视角的覆盖限制、用户扩大范围时的处理方式和成果交付要求。

## 改了什么

- 首轮只比较少量视角，不代表已经穷尽。只提示可能改变建议的未评估因素；新背景使旧视角失效时，替换受影响的部分。
- 默认少问、少量视角、只深入一个分支。用户明确选择更广范围时，按已授权的范围和预算展开。
- 用户已请求的成果继续直接交付；交付前检查一次目标、约束和格式，说明哪些是计划、哪些动作已经完成。
- 合并核心入口的重复文字，保留关键约束。可见文字变短不能证明后台 token 节省。
- 增加 GitHub 使用反馈模板，方便报告理解、选择和交付中的实际帮助或阻碍。
- 更新发布记录，确认 About 简介和八个 Topics 已生效。稳定标识、MIT 与安装程序未改。

## 安装与更新

Windows 下载 `cognitive-perspective-check-v0.2.0-rc.4-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，选一种位置。手动安装下载 `cognitive-perspective-check.zip`。两个 ZIP 的校验值见 `SHA256SUMS.txt`。

同名内容不同时，仍默认保留；按 `INSTALL.md` 显式备份更新。旧版本与附件保留。

## 验证范围

这次做了静态角色走查、内容精简和分发修订，没有新增安装测试或模型行为实验。rc.1 历史记录不能证明 rc.4 的效果。用户收益、自然调用、成本节省和竞品增益仍未验证。
