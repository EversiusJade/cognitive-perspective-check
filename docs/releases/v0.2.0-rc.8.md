# 认知视角检查器 v0.2.0-rc.8

根据用户要的成果和真正缺少的信息，决定直接交付还是补问，减少一缺细节就重新讨论方向的情况。

- 方向已选，且用明确假设就能做出有用成果时，先交付；确实缺少必要材料时，只问阻塞交付的问题。
- 默认用一个短句问一个关键未知，避免把多个信息项塞成“一个问题”。
- 第一轮让选择、证据、代价和条件建议便于扫读，不固定表格、标题或统一字数。
- 对尚未决定的选择，考虑可复用工作、未来切换成本和用户明确的学习目标。不强制肯定预设，也不用过去投入证明继续投入合理。
- 保留 rc.7 的一次 review、已确定任务的停止规则，以及原有提问和视角限额。

取舍和文本 review 见 [修订记录](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.8/docs/reviews/v0.2.0-rc.8-feedback-review.md)。新增演示用于说明预期行为，没有运行新的客户端模型实验。
