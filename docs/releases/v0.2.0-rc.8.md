# 认知视角检查器 v0.2.0-rc.8

按实际请求和关键缺口分流，减少“缺了细节就重新讨论方向”的情况。

- 方向已选、可以用明确假设做出有用成果时先交付；真正缺少必要材料时只问阻塞点。
- 默认一个短句只问一个关键未知，避免把多个信息项塞成“一个问题”。
- 第一轮让选择、证据、代价和条件建议容易扫读，不固定表格、标题或统一字数。
- 尚未决定的选择考虑可复用工作、未来切换成本和用户明确的学习目标；不强制肯定预设，也不以过去投入证明继续投入合理。
- 保留 rc.7 的一次 review、已确定任务停止规则和原有提问与视角限额。

取舍及文本 review 见 [本轮记录](https://github.com/EversiusJade/cognitive-perspective-check/blob/v0.2.0-rc.8/docs/reviews/v0.2.0-rc.8-feedback-review.md)。新增演示说明预期行为，未运行新的客户端模型实验。
