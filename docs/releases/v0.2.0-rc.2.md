# 认知视角检查器 v0.2.0-rc.2

这个候选版修正了项目定位和操作说明。它用于减少早期项目与决策讨论中的认知窄化：先理解背景、找出核心问题，再检查双方预设、比较视角、解释不同条件的后果，给出有条件的建议。

## 改了什么

- 先理解关键背景和内部逻辑，澄清需求只是起点。背景已经清楚，但遗漏了重要视角时，也可以简短检查。
- 只问会改变判断或行动的信息，通常 0–1 个问题，初步理解背景时累计最多 3 个。区分事实、偏好、因果解释和 AI 推断，不替用户编造隐藏目标。
- 通常比较 2 个、最多 3 个有实质差异的视角，说明各自的依据、利益、代价和不确定性。保留原路线最有力的理由，避免只列出同一预设下的不同做法。
- 说明更倾向哪条路线、适用条件，以及什么证据或优先级会改变建议。可以简短解释条件后果；完整推演等用户选定分支后展开，模拟不充当实际证据。
- 增加项目研究目的说明，首页、安装说明和客户端显示名统一为“认知视角检查器”。技能标识和安装目录仍为 `cognitive-perspective-check`。

## 下载与安装

- Windows 用户：下载 `cognitive-perspective-check-v0.2.0-rc.2-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，两种位置选一种。
- 手动安装：下载 `cognitive-perspective-check.zip`，复制完整技能文件夹到客户端支持的技能目录。
- `SHA256SUMS.txt` 提供上述两个 ZIP 的校验值。

已有不同版本时，安装器默认保留现有内容。更新请按仓库 `INSTALL.md` 使用显式替换及备份选项。

## 验证范围

这次没有进行新的模型行为试验，尚未证明能消除偏见、改善真实决策或优于竞品。`evals/validation.md` 保留的是 rc.1 历史记录。流程数量和输出范围是控制工作量的指令，不能保证客户端后台推理的硬 token 上限。
