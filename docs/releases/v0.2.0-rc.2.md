# 认知视角检查器 v0.2.0-rc.2

本候选版修正项目定位和操作说明：以减少早期项目与决策讨论中的认知窄化为目标，将理解背景、识别核心问题、检查双方预设、比较不同视角、解释条件后果和给出条件建议连成一条流程。

## 本次调整

- 理解关键背景与内部逻辑是分析的基础；澄清需求不是完成整个流程的标准。背景清楚但存在重要视角遗漏时，也可以进入简短检查。
- 只补问会改变判断或行动的少量信息，通常 0–1 个问题，初始对齐累计最多 3 个。区分事实、偏好、因果解释和 AI 自身推断，不替用户编造隐藏目标。
- 对照通常 2 个、最多 3 个有实质差异的视角。比较依据、利益、代价和不确定性；保留原路线最有力的理由，避免只给同一预设下的不同实现。
- 给出建议偏向及其适用条件，说明什么证据或优先级会使建议改变。简短条件后果可以帮助理解选择，完整推演由用户选择分支后展开，模拟不充当实际证据。
- 增加项目研究目的说明，统一首页、安装说明和客户端显示名为“认知视角检查器”。技能标识与安装目录仍为 `cognitive-perspective-check`。

## 下载与安装

- Windows 用户：下载 `cognitive-perspective-check-v0.2.0-rc.2-windows.zip`，完整解压后双击 `install-copilot.cmd` 或 `install-shared.cmd`，两种位置选一种。
- 手动安装：下载 `cognitive-perspective-check.zip`，复制完整技能文件夹到客户端支持的技能目录。
- `SHA256SUMS.txt` 提供上述两个 ZIP 的校验值。

已有不同版本时，安装器默认保留现有内容。更新请按仓库 `INSTALL.md` 使用显式替换及备份选项。

## 验证范围

本轮修订未进行新的模型行为试验，不声称已证明能消除偏见、提升真实决策效果或优于竞品。`evals/validation.md` 保留的是 rc.1 历史记录。流程数量与输出范围属于努力控制指令，无法保证客户端后台推理的硬 token 上限。
